# Illustration sources

The SVGs in `docs/assets/` are generated by `gen.py`: hand-authored SVG, with text set in Schibsted Grotesk (`fonts/`, SIL Open Font License), the typeface of sbbench.com, and converted to outlines so it looks the same everywhere. `logo.svg` is the sbbench mark, which follows the viewer's light or dark mode. Edit the script, then:

```bash
cd docs/assets/src
uvx --with fonttools --with uharfbuzz python gen.py .. capture.txt   # writes every SVG into docs/assets/
./render.sh ../memory-check-light.svg light /tmp/memory-check.png   # preview (needs google-chrome)
```

`capture.txt` is real `sbx check` output: regenerate it from a run record with `report.check_table`, never by hand.
