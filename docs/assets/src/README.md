# Illustration sources

The SVGs in `docs/assets/` are generated by `gen.py` (hand-authored SVG, text in the hero converted to outlines from Source Code Pro). Edit the script, then:

```bash
cd docs/assets/src
uvx --with fonttools python gen.py .. capture.txt   # writes every SVG into docs/assets/
./render.sh ../memory-check-light.svg light /tmp/memory-check.png   # preview (needs google-chrome)
```

`capture.txt` is real `sbx check` output: regenerate it from a run record with `report.check_table`, never by hand.
